## 🚀 Como Testar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).

Se preferir rodar com um servidor local:
```bash
# Com Python 3:
python -m http.server 3000

# Ou com npx serve:
npx serve .
```
E acesse no navegador: `http://localhost:3000`.

## 🌐 Como Publicar na Vercel / Netlify

Como este projeto utiliza **HTML5 + Tailwind CSS + Vanilla JS** (sem dependências de build pesadas):

1. **Vercel**:
   - Conecte o repositório no GitHub ou use a CLI: `vercel deploy`.
   - Como é estático, o deploy é instantâneo e gera um link `.vercel.app` gratuito com HTTPS automático.

2. **Netlify**:
   - Basta arrastar a pasta `renda-extra` na tela de upload da Netlify (Drop to deploy).

3. **Hospedagem Tradicional (cPanel/Hostinger/KingHost)**:
   - Faça upload dos arquivos `index.html`, `assets/` para a pasta `public_html`.
